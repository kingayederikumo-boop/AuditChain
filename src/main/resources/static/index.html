How AuditChain protects result sheets

Think of a notebook where each page is stamped with a copy of the page before it. Change an old page and every stamp after it stops matching.

  1. 1

    Save

    An officer sends the figures from a sheet and a photo of it. We save them and give them a unique fingerprint.

  2. 2

    Link

    Each fingerprint also contains the one before it. That is why editing one old sheet breaks every link after it.

  3. 3

    Publish

    Every 6 hours we sign a snapshot of the latest fingerprint and copy it to a public page. Nobody can quietly rewrite history.

  4. 4

    Check

    Anyone can compare the records with the public snapshots. This page does it for you each time you open it.

Needs a second look

A flag means “please check this sheet”. It does not mean fraud has happened.

How to use this site

I am a polling officer
  1. Open “Send a sheet”.
  2. Enter your access code and the polling unit code.
  3. Type each party’s votes and the total written on the sheet.
  4. Add a clear photo of the sheet and press “Send sheet”.
  5. No network? The sheet waits on your phone. Press “Send saved sheets” when you are back online.
I am an observer or journalist
  1. Read the big message at the top. It says whether anything was changed.
  2. Open “Result sheets” to see each sheet and whether its figures add up.
  3. Open “Technical details” to copy a fingerprint and compare it with the public snapshots on GitHub.
I am a reviewer
  1. Look at “Needs a second look” on the checker page.
  2. Compare the figures with the photo of the sheet.
  3. Your decision is made with the review tools and added to the same protected history.

Words used on this site

Fingerprint
A short code worked out from a record. Change one letter in the record and the code changes completely.
Snapshot
A signed copy of the latest fingerprint, kept on a public page outside this site.
Second look
A sheet whose figures do not add up, or that the automatic check was unsure about. A person decides what it means.
Technical details

This is a practice version with made-up data. A clean result means the saved records have not been edited since they were saved. It does not prove the original figures were honest, or that an election result is correct.

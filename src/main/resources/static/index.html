How the check works

  1. Each record is locked to the one before it. Changing one record breaks the lock on every record after it.
  2. Signed checkpoints are published in public on a separate branch, every six hours.
  3. This page compares the two. If history is rewritten, the public checkpoints stop matching.

If the network drops

The submit page keeps a queue on the phone and retries when the network returns. Each submission carries a unique key, so a retry is not counted twice. Power and coverage in the field still need real-world testing.

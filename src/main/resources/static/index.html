How it works

  1. Each record is locked to the one before it. Changing any record breaks the lock on every record after it.
  2. Signed checkpoints are published in public on a separate branch, every six hours.
  3. This page compares the two. If someone rewrites history, the public checkpoints no longer match.

Built for connection loss

The submit page keeps a queue on the phone when the network drops and retries when it returns. Each submission carries a unique key so a retry is not counted twice. Field conditions such as power and coverage still need real-world testing.

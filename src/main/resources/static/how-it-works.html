How AuditChain keeps result sheets safe

Think of a notebook where every page carries a stamp copied from the page before. Change an old page and every stamp after it stops fitting.

  1. 1

    Save

    A polling officer sends the numbers from a sheet and a photo of it. We save them and give them a stamp.

  2. 2

    Connect

    Each stamp also includes the one before it. So changing one old sheet breaks every stamp after it.

  3. 3

    Share

    Every 6 hours we copy the latest stamp to a public page. Nobody can quietly change the past.

  4. 4

    Check

    Anyone can compare the saved sheets with the public copies. This site does it for you every time you open it.

Words used on this site

Stamp
A short code made from a sheet. Change one letter on the sheet and the code changes completely.
Public copy
A copy of the latest stamp, kept on a public page outside this site.
Please check
A sheet whose numbers do not add up, or that our automatic check was unsure about. A person decides what it means.

This only means “please look at this sheet”. It does not mean anyone cheated.

This is a practice version with made-up data. A clean result means the saved sheets have not been edited since they were saved. It does not prove the numbers on the sheets were honest, or that an election result is right.

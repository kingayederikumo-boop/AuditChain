# Datasheet: test data used by AuditChain

Two sets are covered: (A) the organisers' official starter data and (B) the data this project generates itself.

## A. Official synthetic results pack (Rise Networks)

1. **Motivation:** created by the hackathon organisers for practice and testing. Used here to score the screening rules.
2. **Composition:** `results_synthetic.csv`, 900 rows: `pu_id`, `registered_voters`, `accredited_voters`, `votes_A` to `votes_E`, `rejected_votes`. `anomaly_labels_HELD_OUT.csv`, 900 rows: `pu_id`, `anomaly_type`. 42 anomalies (16 accredited_exceeds_registered, 12 suspicious_round_numbers, 8 sum_mismatch, 5 duplicated_from_previous_unit, 1 digit_transposition) and 858 clean. Synthetic. No personal or sensitive data.
3. **Collection process:** generated by the organisers' `tools/generate_synthetic_data.py`. We copied the two files unchanged from the public repository on 2026-11-20.
4. **Preprocessing:** none.
5. **Uses:** scoring arithmetic and plausibility rules. Not for conclusions about real elections or places. The answer key is not used to build the rules.
6. **Distribution:** copies in `src/test/resources/official-synthetic/`, licence CC BY 4.0 (Rise Networks), attribution in `ATTRIBUTION.md`. SHA-256 results `7890642a9dfefdcd50a0ca82cf28aa413896f92fa90c28d29939e59a08785a66`, key `acefc1b42d2fcf63c990fce66535eb8127be4033408719730e7dd79dd17fd1e5`.
7. **Maintenance:** owned by Rise Networks. Errors should be reported to the organisers.
8. **Known limitations:** the organisers describe the distributions as simplistic. Every injected anomaly breaks one arithmetic identity, so the pack cannot show what the rules miss.

## B. Data generated by this project

1. **Motivation:** test and demonstrate the tamper-evident record and the screening.
2. **Composition:** seeded synthetic result sheets (four parties, random votes, seeds 2026 and 7) and 30-entry chains, generated inside the tests. Polling-unit codes such as `PU-1000` are invented.
3. **Collection process:** produced by code in `EvaluationHarnessTest` and `SyntheticDataGenerator`. No outside source.
4. **Preprocessing:** none.
5. **Uses:** tests and demos only. Must not be used to represent real results.
6. **Distribution:** in this repository under the MIT licence.
7. **Maintenance:** the project owner.
8. **Known limitations:** simple random figures, one result format, no natural errors.
